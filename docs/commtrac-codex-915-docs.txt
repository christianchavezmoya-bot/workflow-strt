  <div class="section" id="field-use">
    <div class="section-header">
      <span class="section-num">02</span>
      <span class="section-title">Real-World Field Use Cases</span>
      <div class="section-line"></div>
    </div>
    <p>Codex 915 is designed for installation and service teams who manage complex equipment at customer sites. Here are the primary scenarios:</p>
    <div class="two-col">
      <div>
        <h3>🏭 New Equipment Installation</h3>
        <p>A Project Manager creates a new project linked to a customer and site. Assets (machines) are added to the project. Each asset is assigned a workflow config matching the machine type. Engineers are dispatched, open the app on their iPhone, execute each workflow step on-site — logging serial numbers, photos, and passing inspection checks. Issues found mid-installation are logged and must be resolved before the run can complete. A signature token is generated, emailed to the customer, and they sign on their phone.</p>

        <h3>🔁 Preventive Maintenance Rounds</h3>
        <p>Maintenance engineers use work orders to track PM visits. Work instructions guide them through standard procedures. Inspections are recorded with photos. Completion data syncs back even if cell coverage drops mid-job.</p>
      </div>
      <div>
        <h3>📋 Commissioning Sign-Off</h3>
        <p>After installation, as-built data is captured into the asset's JSON blob. A BOM comparison confirms actual installed components match the spec. Project Manager reviews the dashboard health card showing workflow completion %. Customer receives a signature link and approves remotely.</p>

        <h3>🏢 Multi-Office Management</h3>
        <p>Admins configure multiple offices (regions). Each user belongs to an office. Engineers see only their assigned jobs. Project Managers can filter the dashboard by office. Global admin views all regions simultaneously from the office map.</p>

        <h3>📷 QR-Code Photo Upload</h3>
        <p>Engineers in the field can generate a QR code from the app, scan it with a second phone's camera, and upload photos directly — no login required on the secondary device. Photos are linked to the relevant asset or inspection record.</p>
      </div>
    </div>
  </div>

        <div class="card-title">Notification Triggers</div>

        <div class="card-icon">🔍</div>
        <div class="card-title">Document Indexing</div>
        <div class="card-desc">When a document is uploaded, it is automatically queued for full-text indexing by the background <code>DocumentSearchIndexWorker</code>. No manual trigger needed.</div>

        <div class="card-icon">🔄</div>
        <div class="card-title">Quickbase Sync</div>

      <div class="card" style="--c: var(--warn)">
        <div class="card-icon">🔒</div>
        <div class="card-title">Issue Blocking</div>
        <div class="card-desc">When a blocking issue is logged against a workflow run, the system automatically prevents run completion (returns 422) until the issue is resolved.</div>

        <div class="card-title">JWT Auto-Refresh</div>

        <div class="card-icon">📶</div>

  function showTab(btn, panelId) {
    const container = btn.closest('.section') || document;
    container.querySelectorAll('.tab-btn').forEach(b => b.classList.remove('active'));
    container.querySelectorAll('.tab-panel').forEach(p => p.classList.remove('active'));
    btn.classList.add('active');
    const panel = document.getElementById(panelId);
    if (panel) panel.classList.add('active');
  }

  // Active nav highlight on scroll
  const sections = document.querySelectorAll('[id]');
  const navItems = document.querySelectorAll('.nav-item');
  
  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        const id = entry.target.getAttribute('id');
        navItems.forEach(item => {
          item.classList.toggle('active', item.getAttribute('href') === '#' + id);
        });
      }
    });
  }, { rootMargin: '-20% 0px -70% 0px' });

  sections.forEach(s => observer.observe(s));
</script>
