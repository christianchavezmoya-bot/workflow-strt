        Source anchors

          Platform split to keep honest

          Web browser

          Server-live, not offline-capable

          No queued offline writes
          What works
          Short-lived in-memory read cache, live writes straight to API, normal dashboard/issues/notification surfaces while the server is reachable.
          What does not work
          No IndexedDB local-first browser workflow, no offline unlock, no offline queue, no safe "continue working with no server" browser path.

          Native phone

          Local-first with sync and conflict handling

          Offline-capable
          What works
          Local asset/run caches, offline queue, live sync status chips, Sync Center conflict review, issue updates reflected locally, biometric or PIN unlock with saved session inside the 30-day grace period.
          What still requires server
          First-ever login, any browser session, and any blocked admin/security actions guarded by the offline guard.
